# AI Agent First Review Checklist

Use this checklist for an initial governance review of one agent.

## Agent profile

- [ ] Agent name is documented.
- [ ] Business owner is documented.
- [ ] User population is defined.
- [ ] Intended business purpose is documented.
- [ ] Agent level (1-5) is assigned.

## Data and access

- [ ] Data sources are listed.
- [ ] Sensitive data categories are identified.
- [ ] Access permissions are least-privilege reviewed.
- [ ] Data retention behavior is documented.

## Tools and actions

- [ ] Tool list is complete.
- [ ] Tool permission matrix exists.
- [ ] Write-capable actions are explicitly approved.
- [ ] Irreversible actions are identified.

## Oversight and approval

- [ ] Human approval points are defined for high-impact actions.
- [ ] Escalation path is documented.
- [ ] Kill switch/pause process is documented.

## Testing and operations

- [ ] Prompt injection tests were executed.
- [ ] Unauthorized tool-call tests were executed.
- [ ] Runtime logs capture trigger, tool calls, and final actions.
- [ ] Monitoring owner is assigned.

## Evidence and sign-off

- [ ] Risk summary is completed.
- [ ] Residual risks are documented.
- [ ] Approval decision and approver are recorded.

# Contributing

Thanks for contributing to `ai-agent-risk-framework`.

## Contribution priorities

We especially welcome:

- New practical checklists
- Improved control mappings
- Realistic example agent profiles
- Template improvements for compliance and architecture reviews

## Contribution guidelines

1. Keep changes practical and implementation-oriented.
2. Prefer plain language over legal or vendor jargon.
3. When adding a new risk/control concept, include an example use case.
4. Keep edits narrowly scoped and avoid unrelated refactors.

## Pull request checklist

- [ ] The change has a clear practitioner use case.
- [ ] Terms are consistent with existing docs.
- [ ] New files are linked from `README.md` when relevant.
- [ ] No sensitive data or proprietary policy content is included.

## Reporting issues

When opening an issue, include:

- Agent level
- Risk category
- Where the framework is unclear or incomplete
- Proposed improvement (if available)
